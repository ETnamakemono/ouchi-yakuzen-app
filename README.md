# おうち薬膳

その日の体調と季節から、家にある食材で作れる薬膳レシピを提案する個人用のWebアプリ（PWA）です。

- 悩み（未病）を選ぶ → 東洋医学の考え方による見立て・食養生アドバイス・レシピを表示
- 二十四節気・五行にもとづく季節の養生
- 常備食材のざっくり登録、代用・省略に対応したレシピ提案
- 記録はすべて端末内に保存（外部送信なし）

## 使い方

Android の Chrome で公開ページを開き、メニューから「ホーム画面に追加」を選ぶと、アプリとして使えます。

## 開発

ビルド不要（HTML / CSS / JavaScript のみ）。ローカルで確認するには：

```bash
python tools/devserver.py 8765
```

ファイルを更新したら `sw.js` の `VERSION` を上げてください（アプリに更新通知が出ます）。

## 注意

このアプリは食養生の参考情報であり、医療・診断・治療に代わるものではありません。
